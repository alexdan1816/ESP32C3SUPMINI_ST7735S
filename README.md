# 🖥️ Embedded Display & Firmware Sandbox

> *"Nothing just my hobby, I built stuff that I want to understand. I love building firmware for screen and interact with 'em."*

Welcome to my personal playground! This repository is a collection of my firmware experiments, bare-metal / RTOS drivers, and interactive projects centered around microcontrollers and display modules. 

The goal here isn't just about making things work, but deeply understanding how communication protocols, display controllers, and graphics drivers operate under the hood.

---

## 🚀 What's Inside?

* **Custom Display Drivers:** Writing and porting low-level drivers for various TFT, OLED, and LCD screens (starting with ST7735 and expanding).
* **MCU Firmware:** Clean, modular C/C++ code optimized for microcontrollers (ESP32 series, STM32, etc.).
* **Interactive Peripherals:** Combining screens with sensors, buttons, and state machines for real-time feedback.
* **Hobby & Curiosity Projects:** Small, focused experiments built out of pure passion for embedded systems.
